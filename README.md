# Sumit Bhoi | Portfolio

A modern, responsive personal portfolio website for **Sumit Bhoi**, a Full Stack MERN Developer based in Pune, India. It has a cinematic dark purple theme with a video hero section, smooth scroll animations and a stacked project showcase.

**Live:** https://तुझी-live-link.vercel.app

## Sections
* **Home:** video background hero, intro, social links
* **About:** introduction, education, languages
* **Projects:** featured MERN projects with tech stack and links
* **Skills & Experience:** grouped skills, internship and education
* **Contact:** contact form with email, phone, GitHub and LinkedIn links

## Tech Stack
* React 18 + Vite
* Framer Motion (animations)
* Lucide React (icons)
* Plain CSS (custom design system, glassmorphism)

## Getting Started
```bash
git clone https://github.com/MrSumitbhoi1307/sumit-portfolio.git
cd sumit-portfolio
npm install
npm run dev
```
The site runs at `http://localhost:5173`.

## Build
```bash
npm run build
```

## Customize
All content (name, links, projects, skills) is in `src/data/portfolio.js`.
Contact form: set `VITE_FORM_ENDPOINT` in a `.env` file to use a form service like Formspree.
